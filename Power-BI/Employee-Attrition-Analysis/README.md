# Employee Attrition Analysis Dashboard

## Project Overview

This Power BI project analyzes employee attrition patterns using
employee demographic, job role, department, income, and tenure data.

## Objectives

- Analyze employee attrition rate
- Identify departments with higher employee exits
- Analyze attrition by age group
- Analyze employee exits by job role
- Study employee tenure patterns
- Create an interactive HR analytics dashboard

## Tools Used

- Power BI
- DAX
- Excel / CSV
- Data Visualization
- Data Analysis

## Dashboard Features

- Employees Left KPI
- Attrition Rate
- Average Monthly Income
- Department-wise Attrition
- Age Group Analysis
- Job Role Analysis
- Tenure Analysis
- Interactive Job Role Filter

## Key Skills Demonstrated

- Data Cleaning
- Data Modeling
- DAX
- KPI Creation
- Data Visualization
- Interactive Dashboard Development
- Business Insights
